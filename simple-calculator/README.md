# Simple Calculator

A calculator built with HTML, CSS and JavaScript.

## Features
- Addition, subtraction, multiplication and division
- Chained operations (5 + 3 + 2 = 10)
- Decimal input
- Divide-by-zero handling
- Rounding to avoid floating-point errors (0.1 + 0.2 = 0.3)

## What I learned
DOM events, event delegation, state variables, and debugging with console.log.
